Consignes d'animation

  • Chaque groupe de 4 joue un double ; les autres ateliers peuvent utiliser une capacité adaptée.
  • Les binômes sont renouvelés autant que possible.
  • Le générateur privilégie les ateliers que les joueurs n'ont pas encore faits.
  • Si le nombre de participants ne remplit pas exactement les ateliers, certains joueurs peuvent être en attente : relance une rotation pour les faire tourner.

Conseil : pour 40 joueurs jouant par 4 sur les ateliers, il faut 10 groupes simultanés. Pour des activités par deux, règle la capacité de chaque atelier selon le nombre réel de places.
